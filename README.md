# Zixi She — Academic Homepage

English academic homepage for Zixi She (佘子曦), an undergraduate student at the School of Life Sciences, Fudan University, pursuing a dual bachelor's degree in Biological Sciences and Artificial Intelligence.

Website: https://biosilicon.github.io/

Research interests: Spatial Omics and Cross-omics Translation.

The site includes About, Research Interests, Publications, CV, and Contact. Publications and CV are intentionally empty until the owner provides material.

## Editing

Edit `index.html` for content and `styles.css` for appearance. No installation or build process is required. Open `index.html` locally to preview. The `.nojekyll` file enables plain static file delivery.

To add a CV, upload the approved PDF to `assets/cv.pdf` and enable the link documented in `index.html`. Add only verified citations and paper links to Publications.

GitHub Pages publishes the root of `main`; merged changes trigger the Pages deployment workflow. The initial publication was approved by the owner on October 18, 2026.
